What was trained?

No new model was trained for this search. We reused the MLP trained for 1,000,000 optimizer updates on 20,000 synthetic clean ABRs (one training seed), with batch size 256, AdamW learning rate 0.0002, a 500-update warmup, and zero weight decay. The checkpoint uses EMA rate 0.005. Its denoising training objective is mean squared error in predicted v; it is not an ABR reconstruction loss.

For this experiment the checkpoint is frozen. We vary only guidance during the 200-step reconstruction. The model works in training-standard-deviation-scaled waveform units; EEG values are converted to those same units. This waveform scaling is separate from EEG noise normalization.

How the experiment works

For each clean simulated ABR, we build an EEG by convolving it with known stimulus pulses and adding white noise. Starting from noise, the frozen model estimates an ABR. The pulse matrix predicts the EEG from that estimate; the RMS difference from observed EEG gives a gradient, and guidance determines the size of the update. The EEG residual is divided by √N to make it an RMS, not divided by noise standard deviation.

EEG residual RMS = √mean((observed EEG − predicted EEG)²)
next waveform = diffusion update − guidance × residual gradient
ABR RMSE = √mean((reconstructed ABR − clean reference ABR)²)

All reported RMSE values are in µV. Each clean waveform has a separate simulated EEG at noise SD 0.05, 0.2 and 0.5 µV. Noise SD is used to create and label simulations, not as an input to the reconstruction loss or to choose among different guidance strengths per recording.

How to use this result with the checkpoint

The chosen value applies to this particular checkpoint and its waveform scaling. The checkpoint stores weights under state and a scaling factor under scale; the standalone load_model helper expects a different checkpoint format. Run the following from the Leo directory, with eeg_uv and the equally long pulse train already loaded. Averaging 32 samples matches the test protocol.

import numpy as np
import torch
from model import Denoiser
from dps.reconstruct import reconstruct

checkpoint = torch.load(
    "runs/phoom_matched_10m/step_1000000_ema_0.005.pt",
    map_location="cpu", weights_only=True,
)
model = Denoiser().eval().requires_grad_(False)
model.load_state_dict(checkpoint["state"])
scale_uv = checkpoint["scale"]
draws = [reconstruct(model, eeg_uv / scale_uv, pulses,
                     guidance=6.25, seed=seed)
         for seed in range(32)]
reconstructed_abr_uv = np.mean(draws, axis=0) * scale_uv

The EEG is divided by the model's waveform scale, not by an estimated EEG noise standard deviation. The example uses different random seeds to create 32 draws; exact draws can differ from the batched GPU experiment. Guidance may need retuning for a checkpoint trained with different scaling or for a single reconstruction.

Validation grid and selection

The coarse grid was [0.0, 0.1, 0.3, 1.0, 2.0, 3.0, 4.0, 6.0, 10.0, 20.0]. After finding its best value, the neighboring interval was refined using a nine-point linear grid, excluding already tested points. One global guidance value was selected by minimizing the equally weighted mean of the three noise-level RMSEs. The 32 validation waveforms and 32 test waveforms have distinct generation seeds. Interpretation and limitations

These results establish a comparison for this checkpoint and this simulator. They do not prove an optimum for other checkpoints, pulse patterns, recording lengths, real EEG, or a different number of averaged reconstructions. Selection used eight samples per validation EEG; primary test results use 32, so the optimum may shift with sample count. Only one model training seed was evaluated. The generator uses filtered analytic waveforms and simulated white noise; real EEG has different noise and unknown ground truth. Test results cannot prove clinical or real-recording accuracy.

The accelerated batched sampler uses the same residual and diffusion update as the standalone code. A complete 200-step CPU trajectory was compared numerically against that function (maximum absolute difference 2.1e-07 model units). The main search and primary test used 0.6 minutes; exploratory checks took additional time. No retraining was required. Open the CoreWeave Forge project.

For follow-up, verify the broad guidance range with other training seeds, longer and varied pulse sequences, and realistic correlated EEG noise. Keep a new final test set separate if using these results to tune further.
