MLP versus U-Net: EEG reconstruction

Both models were trained to two million updates and evaluated on two EEG simulation settings. Lower ABR RMSE is better. The realistic set combines known synthetic ABRs with actual speech pulse timings and quiet EEG from a held-out subject. This is a simulation containing real recorded background, with known ABR truth.

Zero-guidance selections: unet real_quiet_native, unet real_quiet_double. Such reconstructions ignore the EEG. Actual speech EEG has no known clean ABR, so a true real-EEG reconstruction RMSE cannot be calculated here.

Method and limitations

The new data uses 500 ms, one 4 kHz-left pulse train, synthetic ABRs, and recorded quiet EEG before first annotated playback, using the original 100× gain correction and 30–2000 Hz/notch preprocessing. Quiet is event-defined, not independently verified. Real speech EEG includes other band/ear responses that the single-regressor exploratory run does not model. Sample size is small and no clinical conclusion follows.
