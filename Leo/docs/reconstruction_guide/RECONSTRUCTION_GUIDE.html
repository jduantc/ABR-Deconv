How my ABR reconstruction works

A step-by-step guide to Leo/dps/reconstruct.py: what goes in, how the model and EEG work together, and what each loss actually measures.

Download all equation PNGs

Start with the goal

Given an EEG recording and the times at which sound pulses occurred, estimate the small auditory brainstem response (ABR) that each pulse produced. The code assumes one shared ABR shape and adds the responses from all pulses together.

Known pulses + EEGStart with random noiseModel proposes an ABREEG guides the estimateRepeat → reconstructed ABR

The ε in this first equation represents EEG measurement noise. The model has learned what ABR-like waveforms look like. The EEG-guidance term checks whether a proposed waveform also explains this recording.

1 · Inputs and output

reconstruct(model, eeg, pulses, *, guidance=0.1, seed=1)
InputMeaning in this function
modelA trained v-prediction network. load_model() sets evaluation mode and freezes its weights.
eegA one-dimensional recording of N samples, in the model’s amplitude units.
pulsesN event weights marking stimulus times. These are event weights, not EEG voltages.
guidanceThe strength of the EEG-based adjustment. The default is 0.1.
seedControls random draws, so a run can be repeated.

The function returns one 256-sample estimated ABR in model units. In this project, one model unit corresponds to 0.1 µV; run_eeg.py divides EEG by 0.1 before reconstruction and multiplies the output by 0.1 to obtain µV.

2 · The stimulus matrix: ABR → predicted EEG

stimulus_matrix(pulses) builds a matrix M with N rows and 256 columns. Each column shifts the pulse train to represent one point of a candidate ABR. Multiplying M by an ABR adds up responses at every pulse time, including overlaps.

matrix = stimulus_matrix(pulses)
predicted_eeg = matrix @ clean[0]

clean has shape (1, 256); clean[0] selects its waveform. The result has N samples, matching eeg. Index 50 of the ABR corresponds to stimulus onset: at 10,000 samples per second, the first 50 samples cover 5 ms before onset. The matrix masks shifts that would fall outside the recording.

Model assumption: each pulse produces the same waveform and overlapping responses add linearly. Whether that is adequate for a real recording is a scientific question.

What clean_from_v does

Given the noisy waveform and predicted v, the following identity estimates the clean waveform. It would recover the training waveform exactly if v were predicted exactly; in practice it is an estimate.

predicted_v = model(current, step)
clean = clean_from_v(current, predicted_v, step, alpha_bar)

Here, current is hₜ and clean is the estimate ĥ₀. The helper’s implementation is signal_weight * noisy - noise_weight * predicted_v.

4 · Initialization

alpha_bar = cosine_schedule()
generator = torch.Generator().manual_seed(seed)
current = torch.randn((1, WAVEFORM_LENGTH), generator=generator)

The schedule has 200 diffusion steps. The reconstruction starts as random noise, not as an EEG waveform. The seed controls this initial noise and the additional diffusion noise drawn later.

5 · The loop, one step at a time

The loop counts backward from t = 199 to t = 0. Each pass makes a candidate clean ABR, checks it against the EEG, and computes the next waveform.

5.1 · Track how the current waveform affects the result

current = current.detach().requires_grad_(True)
step = torch.tensor([t], dtype=torch.long)

detach() separates the current iteration from earlier calculation histories. requires_grad_(True) lets PyTorch calculate how the current waveform affects this iteration’s mismatch. With a model obtained from load_model(), its parameters are frozen. The reconstruction function itself performs no optimizer update, even if a caller passes an unfrozen model.

5.2 · Estimate a clean ABR

predicted_v = model(current, step)
clean = clean_from_v(current, predicted_v, step, alpha_bar)

The model uses t to know the current noise level. The helper applies the clean-estimate equation above.

5.3 · Predict the recording and measure its mismatch

predicted_eeg = matrix @ clean[0]
residual = eeg - predicted_eeg
loss = torch.linalg.vector_norm(residual) / np.sqrt(len(eeg))

Here y is the observed EEG, M is the stimulus matrix, and N is the number of EEG samples. The result is the root mean square of the EEG residual. It measures how well the candidate explains the recording; it is not the reconstruction RMSE against a known ABR.

5.4 · Get the guidance direction

gradient = torch.autograd.grad(loss, current)[0]

PyTorch differentiates through the predicted EEG, clean estimate, and network back to current. The gradient points toward increasing mismatch; the update subtracts it to nudge the waveform toward a lower mismatch.

5.5 · What are we trying to do next?

At the start of this block, current is the noisy ABR waveform at step t, clean is the network’s estimate of the final clean ABR, and gradient tells us how the EEG mismatch changes with current. Each is a waveform with 256 values. The loop moves backward from t = 199 toward 0, making a new current at each step.

Current noisy waveformCalculate a cleaner diffusion stepAdd scheduled randomnessNudge using the EEG

5.6 · Look up the current and next noise levels

a = alpha_bar[t]
previous_a = alpha_bar[t - 1] if t > 0 else torch.tensor(1.0)

alpha_bar is a precomputed schedule describing how much of the original signal is retained after forward diffusion. In the noising equation in section 3, the clean waveform is multiplied by the square root of this value, and the noise by the square root of one minus this value. Values near 1 correspond to less noise; values near 0 correspond to more noise.

a is the schedule value at the current step t. previous_a is the value at t − 1: the next, cleaner stage during reconstruction. At t = 0 there is no earlier array entry, so the code uses 1 to represent the clean endpoint.

5.7 · Find the coefficients for this one step

alpha = a / previous_a
beta = 1 - alpha

a and previous_a are cumulative schedule values. Their ratio, alpha, describes signal retention for the single transition between these two stages; beta describes the corresponding forward-step noise variance. The code uses them to calculate the reverse step.

5.8 · Find the center of the next step

mean = (previous_a.sqrt() * beta / (1 - a)) * clean
mean = mean + (alpha.sqrt() * (1 - previous_a) / (1 - a)) * current

Read the two lines together as mean = clean_weight * clean + current_weight * current. The weights come from the noise schedule. The first line takes part of the network’s predicted clean ABR; the second adds part of the current noisy waveform. They are calculated for every step and applied to every waveform point.

mean is a 256-point waveform, not one average number. It is the center of the reverse-diffusion distribution: the default next waveform before the random and EEG-guidance terms are added. The network’s clean is an estimate, so it need not be the true ABR.

5.9 · Set the random part

variance = beta * (1 - previous_a) / (1 - a)
noise = torch.randn(current.shape, generator=generator) if t > 0 else 0

variance controls how widely the next sample can vary around mean. For t > 0, torch.randn draws Gaussian noise with one value for each point of the waveform. A fixed seed makes these draws reproducible. At t = 0, the code draws no new noise and sets this term to zero.

5.10 · Combine denoising, randomness, and EEG guidance

current = mean + variance.sqrt() * noise - guidance * gradient
TermWhat it does
meanProvides the center of the next, cleaner diffusion step.
variance.sqrt() * noiseAdds random variation at the scheduled scale. The square root converts variance to the standard deviation used to scale Gaussian noise.
- guidance * gradientUses the EEG mismatch to nudge the waveform. The gradient points locally toward increasing the loss with respect to current; subtracting it points toward decreasing that loss.

These terms act on all 256 waveform values. The gradient was calculated through the predicted EEG, clean, and the network back to the old current. It is combined with the diffusion step; because the mean and random term also move the waveform, the EEG loss is not guaranteed to decrease at every iteration.

λ is guidance. If guidance is zero, the EEG does not steer the output. Larger values strengthen the correction; in this implementation the correction is not multiplied by the diffusion variance. Choose guidance on separate validation data. To reproduce an earlier update for a fixed recording, divide the old guidance value by the old noise SD in model units.

5.11 · A worked example for one waveform point

These are illustrative values, not measured results. In a real iteration the same schedule coefficients apply to all waveform points, while the clean estimate, current value, noise and gradient vary by point. Suppose a = 0.60, previous_a = 0.75, clean = 0.80, current = 0.40, noise = -0.20, gradient = 0.10 and guidance = 0.20. Then:

In this example the diffusion mean moves the point from 0.40 to about 0.570; the random term subtracts about 0.071, and the EEG-guidance term subtracts 0.020. The model and the EEG are therefore both involved in the next value.

5.12 · The last step

At t = 0, previous_a = 1. Substituting that value makes mean = clean and variance = 0. No new random noise is drawn, so the last update simplifies to:

current = clean - guidance * gradient

After this last correction, the function returns current.detach().numpy()[0] as the estimated ABR. The model weights are not trained or changed by this loop.

6 · Three different errors

QuantityWhat is compared?Purpose
Training v-MSEPredicted v vs the known training target vTrain and validate the network’s diffusion prediction.
Guidance lossObserved EEG vs EEG predicted by the current ABR estimate; RMS across EEG samplesCalculate the gradient that steers each reconstruction step.
Reconstruction RMSEFinal reconstructed ABR vs a known reference ABREvaluate recovery in a simulation or other setting with a reference.

For real EEG the true ABR is generally unknown, so this exact reference-based RMSE is not directly available. The simulated experiments start from a known reference, use it to generate noisy EEG, reconstruct, then calculate this error. If the reference and reconstruction are in model units, multiply the RMSE by 0.1 to report µV.

7 · One sample versus many

This particular reconstruct() call returns one sample. Repeating it with different seeds can produce different waveforms. An experiment may average several samples before calculating RMSE, or calculate RMSE for each sample and average those errors. Those are different measurements.

The separate batched experiment code runs the same kind of guidance calculation for multiple observations. The existing batched experiment implementations still use their original noise-normalized loss, so their historical results are unchanged. Later experiments may also apply a covariance-based correction after averaging; that correction is not part of this function.

"""Reconstruct an ABR from EEG using DPS"""

import sys
from pathlib import Path

import numpy as np
import torch

sys.path.insert(0, str(Path(__file__).resolve().parents[1]))
from data import WAVEFORM_LENGTH
from diffusion import clean_from_v, cosine_schedule
from model import make_model


def stimulus_matrix(pulses, response_length=WAVEFORM_LENGTH, onset_index=50):
    """Use the pulse timings to turn one ABR into an EEG signal."""
    pulses = torch.as_tensor(pulses, dtype=torch.float32)
    if pulses.ndim != 1 or len(pulses) == 0:
        raise ValueError("pulses must be a nonempty one-dimensional array")
    # Our ABR starts 50 samples before the pulse, so keep that offset here.
    eeg_times = torch.arange(len(pulses))[:, None]
    abr_times = torch.arange(response_length)[None, :] - onset_index
    indices = eeg_times - abr_times
    valid = (indices >= 0) & (indices < len(pulses))
    return pulses[indices.clamp(0, len(pulses) - 1)] * valid


def load_model(checkpoint_path):
    checkpoint = torch.load(checkpoint_path, map_location="cpu", weights_only=True)
    model = make_model(checkpoint.get("architecture", "mlp"))
    model.load_state_dict(checkpoint["model"])
    model.eval()
    for parameter in model.parameters():
        parameter.requires_grad_(False)
    return model


def reconstruct(model, eeg, pulses, *, guidance=0.1, seed=1):
    """Start with some noise and use the EEG to guide the ABR reconstruction

    EEG must be in the model's amplitude unit.
    The pulse train contains event weights, not EEG voltages.
    """
    if guidance < 0:
        raise ValueError("guidance must be nonnegative")
    eeg = torch.as_tensor(eeg, dtype=torch.float32)
    matrix = stimulus_matrix(pulses)
    if eeg.ndim != 1 or len(eeg) != len(matrix):
        raise ValueError("eeg and pulses must be 1D arrays of the same length")
    alpha_bar = cosine_schedule()
    generator = torch.Generator().manual_seed(seed)
    current = torch.randn((1, WAVEFORM_LENGTH), generator=generator)

    for t in range(len(alpha_bar) - 1, -1, -1):
        current = current.detach().requires_grad_(True)
        step = torch.tensor([t], dtype=torch.long)
        predicted_v = model(current, step)
        clean = clean_from_v(current, predicted_v, step, alpha_bar)
        predicted_eeg = matrix @ clean[0]

        # See how well this ABR explains the EEG, then get a direction to fix it
        residual = eeg - predicted_eeg
        loss = torch.linalg.vector_norm(residual) / np.sqrt(len(eeg))
        gradient = torch.autograd.grad(loss, current)[0]

        # Take one step towards less noise and nudge it using the EEG.
        a = alpha_bar[t]
        previous_a = alpha_bar[t - 1] if t > 0 else torch.tensor(1.0)
        alpha = a / previous_a
        beta = 1 - alpha
        mean = (previous_a.sqrt() * beta / (1 - a)) * clean
        mean = mean + (alpha.sqrt() * (1 - previous_a) / (1 - a)) * current
        variance = beta * (1 - previous_a) / (1 - a)
        noise = torch.randn(current.shape, generator=generator) if t > 0 else 0
        current = mean + variance.sqrt() * noise - guidance * gradient

    return current.detach().numpy()[0]
